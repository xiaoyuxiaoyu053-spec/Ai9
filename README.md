# DeepLine 1.7.0 — iMessage 风格、自动朗读与金币系统

这是 Android Studio / GitHub Actions 工程源码，Android 工程位于 `android/`，不是可直接安装的 APK。

## 本版新增

- AI 新消息自动语音朗读：默认开启，可在“设置 → 高级设置 → AI 消息自动朗读”关闭。使用手机系统的中文 TTS，沿用男/女声偏好、中文音色、音调和语速设置；实际音色取决于设备语音引擎。打开私聊页面后，新收到的 AI 消息会自动朗读，不会进入聊天时把旧记录全部重新念一遍。
- 本地金币：首次默认 100 枚，每经过 1 秒增加 1 枚；金币余额和最后计息时间保存在本机，退出应用后再次打开时也会按经过的秒数补算。
- 红包/转账：发送时检查余额并扣除金币；AI 接受后保持扣款，AI 拒绝后返还；接受 AI 发来的红包/转账会增加金币。以上完全是 DeepLine 本地虚拟互动，不会触发真实支付。
- 完整 ZIP 备份会保存金币余额、计时戳和自动朗读设置。

## 已保留的先前需求

- iMessage 风格私聊、毛玻璃和圆润按钮、居中头像/名称、AM/PM 时间、已读状态与消息动画。
- 图片作为真实文件附件交给支持视觉输入的模型；GIF 导入；复制/引用/删除消息。
- 红包和转账卡片、AI 接受或拒绝、可自定义金额与备注。
- 群聊可邀请多个自建 AI，每个 AI 单独调用自己的 API 并读取前面的群聊消息；每轮每个 AI 最多回复一次。
- 微信风格朋友圈，封面自定义，用户与 AI 可以发布、点赞/不点赞、评论。
- AI 多条回复设置（随机 1 到最多 4 条）、全局字体/TTF、色盘、主题和气泡颜色、记忆条数设置。
- 每个 AI 独立配置 DeepSeek、Claude、豆包 Ark、OpenAI API Key 和模型/接入点 ID。
- 长按 AI 导出 ZIP；创建 AI 可选择“导入 ZIP”或“自定义”；备份包含角色、聊天记录、设置与本地媒体。
- 之前取消的登录、后端、管理员或公共账户系统没有添加。

## 构建 APK

1. 将本项目内容上传至 GitHub 仓库根目录，确保 `android/` 文件夹位于根目录。
2. 在 GitHub Actions 运行 `Build DeepLine APK`。
3. 成功后下载 `DeepLine-debug-apk` artifact，解压得到 APK。

## 注意

- API Key、聊天记录与媒体可能包含个人数据；完整 ZIP 备份包含这些信息，请勿上传公开仓库或分享给陌生人。
- 红包、转账和金币只保存在本地，不是真实金融功能。
- 当前环境没有运行 Android SDK/Gradle 编译；请用 GitHub Actions 实际构建。如构建失败，需按新的 Kotlin/Gradle 日志继续修复。
